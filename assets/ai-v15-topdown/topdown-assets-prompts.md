# v15 Top-Down Asset Prompt Set

This batch was generated as assets only. It corrects the previous oblique,
single-angle combat-unit look by using flat orthographic top-down art.

## Unit Direction Sheets

Shared structure:

- Asset type: 4x4 sprite sheet with 16 top-down directional frames.
- Composition: orthographic top-down, no horizon, one unit per cell, transparent or plain dark background, same size and lighting across all cells.
- Direction order: E, ESE, SE, SSE, S, SSW, SW, WSW, W, WNW, NW, NNW, N, NNE, NE, ENE.
- Style: Japanese Tactical HD-2D, readable Canvas game sprite, hand-painted armor detail, bright accents.

Generated units:

- Player assault Raijin: fast narrow hull, long forward cannon, red and gold accent.
- Player balanced Ironclad: medium command tank, square dependable hull, blue reactor accent.
- Player heavy Genbu: broad heavy tank, twin cannon, shield plating, teal core.
- Wingman assault: compact attack drone tank, agile silhouette, gold/red glow.
- Wingman guard: compact shield-support drone, round emitters, blue glow.
- Wingman flex: adaptive tactical drone, asymmetrical sensor pods, green glow.
- Enemy crimson tank: red-black standard enemy armor.
- Enemy crimson carrier: support carrier/truck silhouette, crimson markings.
- Boss crimson landship: wide boss landship with heavy turrets.
- Support airstrike aircraft: top-down aircraft for future airstrike support.

## Terrain Atlases

Shared structure:

- Asset type: modular 4x4 terrain tile atlas with 16 usable square tiles.
- Composition: orthographic top-down, equal square cells, no UI labels, no horizon, no large object crossing tile boundaries.
- Purpose: maps can assemble multiple terrain types from the same stage atlas, or mix tiles across stage atlases if needed.

Generated stages:

- Stage 01 desert outpost: sand, road, oasis edge, rocks, wreck, crater, cover, ruins.
- Stage 02 rain city: wet asphalt, road intersections, shallow water, concrete, fence, debris.
- Stage 03 forest shrine: moss ground, dirt road, pond edge, boulder, log, shrine debris.
- Stage 04 industrial ruins: cracked concrete, metal roads, drains, barricades, pipes, factory debris.
- Stage 05 snow battlefield: snow ground, compacted roads, ice, frozen boulders, snow cover, bunker rubble.
- Stage 06 night fortress: stone slabs, fortress roads, energy floor, electric fence, fortress masonry.
- Stage 07 final battlefield: scorched ground, asphalt, lava cracks, black rocks, smoke, final fortress debris.
